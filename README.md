# Bodega

A static, interactive front-end recreation of the Bodega Figma prototype. The public site includes Home, Demo, and Our Story. The sample workspace includes all seven modules.

## Demo data

Sign-in and operations use sample data. Changes and demo requests are kept in the browser. CSV reports download directly from the browser. The site does not authenticate accounts, send requests, or sync inventory to a server.

The warehouse photos were exported from the supplied Figma design. Photo credit is shown in the site footer.
